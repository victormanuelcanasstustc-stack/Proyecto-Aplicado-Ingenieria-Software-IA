# Bitácora – Parte B: Claude Code

## Contexto

Este documento registra el proceso de trabajo realizado sobre el repositorio utilizado para la Parte B del proyecto aplicado de Ingeniería de Software con IA.

El proyecto original corresponde a una aplicación académica desarrollada con TypeScript y Node.js.

## Registro 1 – Preparación del repositorio

### Actividad
Se preparó el repositorio existente para comenzar el proceso de trabajo de la Parte B.

### Acciones realizadas
- Se creó un repositorio Git local.
- Se revisó la estructura inicial del proyecto.
- Se creó el archivo `.gitignore`.
- Se excluyó `node_modules/` del control de versiones.
- Se creó `CLAUDE.md` con la descripción, convenciones, restricciones y flujo de trabajo del proyecto.

### Decisiones técnicas
Se decidió utilizar Git desde el inicio para poder registrar los cambios de manera progresiva y mantener un historial del desarrollo.

### Estado
Completado.

---

## Registro 2 – Acceso a Claude Code

### Situación
La actividad requiere utilizar Claude Code para realizar las etapas de:

Explorar → Planificar → Programar → Commit.

El acceso fue solicitado previamente, pero la cuenta disponible actualmente no permite utilizar Claude Code porque corresponde a un plan que no incluye esta funcionalidad.

### Acción realizada
Se informó previamente al docente sobre la falta de acceso, siguiendo la indicación incluida en las instrucciones del proyecto.

### Decisión técnica
Mientras se espera una respuesta o una alternativa de acceso, se decidió continuar preparando los elementos del proyecto que pueden desarrollarse sin utilizar Claude Code.

### Importante
No se registrarán como realizadas actividades que requieran Claude Code hasta contar con acceso real a la herramienta.

### Estado
Pendiente de acceso.

---

## Registro 3 – Preparación de la nueva funcionalidad

### Propuesta
Se propone mejorar el asistente académico existente mediante una funcionalidad de consulta académica estructurada.

### Objetivo
Permitir consultas relacionadas con estudiantes y calificaciones de manera más organizada y segura, manteniendo las funcionalidades actuales.

### Consideraciones
La nueva funcionalidad deberá:

- validar los datos recibidos;
- mantener las funcionalidades existentes;
- evitar acceso no autorizado a información académica;
- producir respuestas consistentes;
- contar con pruebas automatizadas;
- mantener la protección contra instrucciones maliciosas o intentos de manipulación.

### Estado
Diseño preliminar preparado.

---

## Registro 4 – Pendiente de ejecución con Claude Code

Las siguientes actividades requieren acceso real a Claude Code:

1. Exploración realizada por Claude Code.
2. Análisis generado por Claude Code.
3. Plan de implementación generado por Claude Code.
4. Revisión y modificación del plan.
5. Implementación mediante Claude Code.
6. Evidencias de las interacciones.
7. Registro de los commits realizados durante el flujo.

Estas actividades serán realizadas cuando exista acceso autorizado a Claude Code.

## Nota final

La bitácora mantiene separados los trabajos realizados manualmente de las actividades que requieren una herramienta externa. Esto permite conservar un registro transparente del proceso de desarrollo.
